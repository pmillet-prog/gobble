# Special Elite

Special Elite Regular, by Astigmatic (Brian J. Bonislawsky), is used locally for
the statistics binder's titles, tabs, and controls. The typeface is distributed
under the Apache License 2.0; the unchanged upstream license is in `LICENSE.txt`.

- Official family source: https://github.com/google/fonts/tree/main/apache/specialelite
- Official metadata: https://raw.githubusercontent.com/google/fonts/main/apache/specialelite/METADATA.pb
- Official license: https://raw.githubusercontent.com/google/fonts/main/apache/specialelite/LICENSE.txt
- Google Fonts stylesheet: https://fonts.googleapis.com/css2?family=Special+Elite&display=swap
- Downloaded: 2026-10-08
- Style: normal
- Weight: 400
- Format: WOFF2, version served as `v20`

The font binaries are the unmodified files served by Google Fonts:

| Local file | Official download |
| --- | --- |
| `SpecialElite-Regular-latin.woff2` | https://fonts.gstatic.com/s/specialelite/v20/XLYgIZbkc4JPUL5CVArUVL0ntnAOSA.woff2 |
| `SpecialElite-Regular-latin-ext.woff2` | https://fonts.gstatic.com/s/specialelite/v20/XLYgIZbkc4JPUL5CVArUVL0ntn4OSEFt.woff2 |

The Latin subset covers French accents and the `œ` ligature. The Latin Extended
subset supplies the remaining supported extended Latin characters. Keep the
official Unicode ranges on the two `@font-face` declarations so browsers only
download the subset they need. No remote Google Fonts stylesheet or runtime
font request is required.
