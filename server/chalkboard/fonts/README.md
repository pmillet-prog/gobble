# Export fallback font

`NotoEmoji.ttf` is the unmodified Noto Emoji variable font from Google Fonts:
https://github.com/google/fonts/tree/main/ofl/notoemoji

Downloaded on 2026-11-08 from:
https://raw.githubusercontent.com/google/fonts/main/ofl/notoemoji/NotoEmoji%5Bwght%5D.ttf

The accompanying `NotoEmoji-OFL.txt` contains its SIL Open Font License.
This font is used only by the server PNG exporter, after the selected chalk
face and the existing Caveat font. It is not downloaded by game clients.
